# A. 仿真基础（MuJoCo）

### A1 物理引擎
- **人话**：给定模型和控制量，算出下一时刻每个物体在哪、受多大力。
- **类比**：机器人的飞行模拟器。它不管“策略”，只管“物理”。
- **代码**：`mujoco.MjModel.from_xml_path()` 加载，`mujoco.mj_step()` 推进。
- **术语**：physics engine / rigid body simulator。
- **面试**：MuJoCo 是接触建模准、轻量的物理引擎，适合具身智能的仿真迭代。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### A2 mjModel / mjData
- **人话**：model 是说明书（不变），data 是当前状态（每步都变）。
- **类比**：游戏角色的属性表 vs 当前的血量和坐标。
- **代码**：`m = MjModel...`；`d = MjData(m)`；`d.qpos`、`d.xpos`、`d.ctrl`。
- **术语**：model–data separation。
- **面试**：MuJoCo 把静态模型和运行时状态分开，避免每步重复解析模型。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### A3 mj_step / mj_forward
- **人话**：step 推进一步物理；forward 只算当前状态、不推进时间。
- **类比**：forward 是“看一眼现在在哪”，step 是“往前走一步”。
- **代码**：`mujoco.mj_step(m, d)`；`mujoco.mj_forward(m, d)`。
- **术语**：forward dynamics / integration。
- **面试**：调试和采数据用 forward，仿真推进用 step。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### A4 时间步 timestep
- **人话**：每一步代表多少秒。Panda 场景是 0.002 秒。
- **类比**：视频帧率。步长太大，画面会跳，物理会炸。
- **代码**：`model.opt.timestep`；1000 步 = 2 秒。
- **术语**：integration timestep。
- **面试**：步长过大接触会穿透、积分会发散；Panda 用 2ms + implicitfast 积分器。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### A5 MJCF 模型文件
- **人话**：用 XML 描述机器人：连杆、关节、电机、质量、碰撞形状。
- **类比**：机器人的说明书，或者乐高图纸。
- **代码**：`scene_pick.xml`（场景）、`panda.xml`（机器人本体）。
- **术语**：MJCF（MuJoCo XML Format）。
- **面试**：能用 MJCF 定义场景、加物体和传感器；`include` 和 `meshdir` 按模型文件所在目录解析。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

# B. 运动学

### B1 位姿与坐标系
- **人话**：位置（3 个数）+ 姿态（3 个转动），描述物体在哪、朝哪。
- **类比**：快递地址 + 门朝哪个方向。
- **代码**：`d.xpos`（位置）、`d.xmat`（旋转矩阵）、`d.xquat`（四元数）。
- **术语**：pose / frame / rotation matrix / quaternion。
- **面试**：位姿是 6 自由度；旋转矩阵直观但冗余，四元数紧凑但反直觉，各有取舍。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### B2 正运动学 FK
- **人话**：给关节角，顺着连杆一路算，得到末端在哪。
- **类比**：知道每个关节弯多少，算出指尖的位置。
- **代码**：`mj_forward()` 之后读 `d.xpos[hand]`。
- **术语**：forward kinematics。
- **面试**：FK 是唯一确定的，给定关节角必有唯一末端位姿。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### B3 雅可比 J
- **人话**：一张 3×7 的灵敏度表：第 j 个关节转一点，手在 x/y/z 各移动多少。
- **类比**：七个旋钮控制三个指标，表告诉你每个旋钮对每个指标的影响。
- **代码**：`mujoco.mj_jacBody(m, d, jacp, jacr, hand)`；05 实验数值验证。
- **术语**：Jacobian。
- **面试**：J 把关节速度映射到末端速度；每一列是一个关节的灵敏度，单位米/弧度。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### B4 逆运动学 IK
- **人话**：给手的目标位姿，反推关节角。没有解析公式，只能迭代。
- **类比**：导航里输入地址，反推方向盘该转多少。
- **代码**：`04_pick_place.py` 里的 `solve_ik()`。
- **术语**：inverse kinematics。
- **面试**：冗余 + 非线性导致多解，用雅可比把位置误差转成关节增量，迭代逼近。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### B5 冗余自由度
- **人话**：关节比任务需要的多，同一个手位有无穷多种关节组合。
- **类比**：七个人抬一张桌子，三个人就够，分法有很多。
- **代码**：Panda 7 个关节，手只要 6 个自由度，多出 1 个。
- **术语**：redundancy。
- **面试**：冗余带来多解，必须再加一个准则（比如最小范数）才能挑出唯一解。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### B6 伪逆
- **人话**：在无穷多种分法里，自动挑“总转动量最小”的那个。
- **类比**：抬桌子时让每个人出力最均衡、总出力最小。
- **代码**：`J.T @ np.linalg.solve(J @ J.T + damp*I, e)`。
- **术语**：Moore–Penrose pseudoinverse / minimum-norm solution。
- **面试**：方程少于未知数时用伪逆，得到最小范数解。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### B7 奇异位形 / 降秩 / 病态
- **人话**：某些姿势下手某个方向动不了（奇异）；独立方向变少（降秩）；求逆相当于除以接近零的数（病态）。
- **类比**：手臂完全伸直推墙——往前这个方向锁死了；方向盘打满。
- **代码**：`damp=0` + 超范围目标 `[0.55, 0, 0.95]` 的实验。
- **术语**：singularity / rank deficiency / ill-conditioning。
- **面试**：奇异位形下 J 降秩，伪逆病态，关节速度指令会爆炸。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### B8 阻尼正则化
- **人话**：给矩阵对角线加一个小正数，保证永远可逆、解有界；代价是精度略降。
- **类比**：分母加个底，防止除以零。
- **代码**：`damp=1e-3`；`J Jᵀ + λI`。
- **术语**：damped least squares / Tikhonov regularization。
- **面试**：阻尼是正则化，牺牲精度换稳定；太大收敛慢、残差大，太小边界处会抖。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

# C. 控制

### C1 执行器与 ctrl
- **人话**：ctrl 是发给电机的目标值。
- **类比**：遥控器的摇杆。
- **代码**：`d.ctrl[:7]` 是七个关节；`d.ctrl[7]` 是夹爪（255 开、0 合）。
- **术语**：actuator / control input。
- **面试**：Panda 的 ctrl 是关节目标角，由 PD 控制器跟踪。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### C2 PD 控制
- **人话**：力矩 = Kp × 角度误差 − Kd × 角速度。比例项拉回目标，微分项刹车。
- **类比**：开车回正方向：偏得多就多打，快到了就回一点，不然会来回摆。
- **代码**：`gainprm="4500"`、`biasprm="0 -4500 -450"`。
- **术语**：PD control。
- **面试**：PD 参数决定刚度和阻尼；目标阶跃会产生大力矩，所以要插值。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### C3 轨迹插值
- **人话**：目标角从当前值平滑过渡到目标值，而不是瞬间跳变。
- **类比**：电梯加速、匀速、减速，不能瞬移。
- **代码**：`move_to()` 里的 `(1-a)*q_start + a*q_target`。
- **术语**：trajectory interpolation。
- **面试**：插值避免阶跃指令导致力矩饱和和机械冲击。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

# D. 接触与抓取

### D1 刚体（质量 / 惯量）
- **人话**：有质量、惯量、形状的物体，受力和力矩驱动。
- **类比**：不同重量的箱子，推起来手感不同。
- **代码**：`mass="0.05"`；`<inertial>` 里的质量、惯量。
- **术语**：rigid body / inertia。
- **面试**：质量影响惯性力，惯量影响转动难易；仿真里参数要和真实物体对齐。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### D2 摩擦与法向力
- **人话**：接触面之间的阻力，上限是摩擦系数 × 法向力（μN）。
- **类比**：夹肥皂和夹铁块，手感完全不同。
- **代码**：geom 的 `friction`，默认 `1 0.005 0.0001`。
- **术语**：Coulomb friction。
- **面试**：夹持靠摩擦，需要 μN ≥ mg；仿真摩擦参数直接影响 sim2real。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### D3 夹爪与开合宽度
- **人话**：夹爪能张开的宽度有限。Panda 两指最大约 8 厘米。
- **类比**：手再大也夹不住更大的箱子。
- **代码**：`finger_joint` 范围 0–0.04，两指合计 0.08 米。
- **术语**：gripper / end effector。
- **面试**：抓取失败常常是几何不匹配，而不是力不够——这是容易答深的地方。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

### D4 自由关节 freejoint
- **人话**：给物体 6 个自由度，让它能被推动、被抓起、掉落。
- **类比**：把方块从“焊死在空气里”变成“真的放在桌上”。
- **代码**：`<freejoint name="cube_free"/>`。
- **术语**：free joint / floating base。
- **面试**：被抓物体需要 freejoint 才能被物理引擎驱动。
- **掌握**：☐ 能复述 ☐ 能解释 ☐ 能改代码 ☐ 能面试

## 记忆口诀

- **damp** 管“算得出来，但别炸”
- **插值** 管“目标别跳”
- **PD** 管“追得上”
- **DP** 管“学得会”

## 一张图

```
[规划层]  IK 迭代：q → FK → J → (JJᵀ+λI)⁻¹ → dq → q
                              ↑
                         damp 在这里（纯数学，不碰物理）

[执行层]  q_target → 插值 → ctrl → PD → torque → 物理 → qpos
```

damp 不改变“降秩”这件事，它只改变降秩之后算出来的数有多大。
