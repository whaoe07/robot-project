## 2. 离线规划（无物理、无时间）

### 2.1 任务分解

把“抓取放置”拆成子目标：

```
home → 预抓取 → 抓取 → 抬起 → 放置 → 松开
```

每个子目标对应一个**笛卡尔位姿**（位置 + 姿态），比如：

| 子目标 | 手的目标位置 | 姿态 |
|---|---|---|
| 预抓取 | `[0.55, 0, 0.56]` | 朝下 |
| 抓取 | `[0.55, 0, 0.505]` | 朝下 |
| 抬起 | `[0.55, 0, 0.63]` | 朝下 |
| 放置 | `[0.38, 0.18, 0.63]` | 朝下 |

### 2.2 IK 迭代（算法核心）

对每个目标位姿，求解七个关节角：

```
输入：目标位置 p*，目标姿态 R*，初始猜测 q
重复 600 次：
  1. 把 q 写进 data.qpos[:7]
  2. mj_forward  → 得到当前手的位置 p 和姿态 R（正运动学）
  3. 算误差：
       e_p = p* − p
       e_r = 由 R 和 R* 算出的旋转误差
       e   = [e_p; e_r]              （6 维）
  4. mj_jacBody → 得到 J（6×7，位置 3 行 + 姿态 3 行）
  5. 阻尼伪逆：
       dq = Jᵀ (J Jᵀ + λI)⁻¹ e
  6. 走一小步并限位：
       q ← clip(q + 0.6·dq, 关节下限, 关节上限)
  7. 如果 |e_p| < 1e-3 且 |e_r| < 1e-2，提前退出
输出：q_target
```

- **算法**：正运动学 + 雅可比 + 阻尼最小二乘
- **物理**：无
- **时间**：不走
- **迭代次数 ≠ 仿真时间**：600 次是数学收敛，不是 600×0.002 秒
- **代码**：`04_pick_place.py` 的 `solve_ik()`

### 2.3 输出：路标序列

```
[q_home, q_pre, q_grasp, q_lift, q_place]
```

每个都是 7 维关节角。IK 到此结束，它不知道“怎么走”。

## 3. 在线执行（有物理、有时间）

### 3.1 插值：路标之间怎么走

```python
for i in range(n):
    a = (i + 1) / n
    d.ctrl[:7] = (1 - a) * q_start + a * q_target
```

- **算法**：关节空间线性插值
- **物理**：无（只是算目标）
- **时间**：这一步不算时间，下一步 `mj_step` 才推进

### 3.2 夹爪：独立的执行器

```python
d.ctrl[7] = 255   # 张开
d.ctrl[7] = 0     # 闭合
```

- 夹爪和手臂**不是一个模块**，各自有执行器
- 闭合时手指挤压方块，**接触力**产生，摩擦力托住方块
- 抓取不是“绑定”，是物理涌现

### 3.3 mj_step：物理引擎内部

每调用一次 `mj_step`，引擎按顺序做五件事：

```
① 位置阶段（mj_fwdPosition）
   - 正运动学：算每个 body 的 xpos、xmat
   - 碰撞检测：算哪些 geom 接触
   - 建立约束

② 速度阶段（mj_fwdVelocity）
   - 科里奥利力、离心力
   - 弹簧、阻尼等被动力

③ 执行器阶段（mj_fwdActuation）
   - 根据 ctrl 算电机力
   - Panda：force = 4500·(ctrl − qpos) − 450·qvel
   - 再被 forcerange 截断（±87 N·m）

④ 加速度阶段（mj_fwdAcceleration + mj_fwdConstraint）
   - 解 M·q̈ = 外力 + 约束力
   - 得到关节加速度

⑤ 积分（积分器）
   - qvel ← qvel + q̈·dt
   - qpos ← qpos + qvel·dt
   - time ← time + 0.002
```

- **物理**：有
- **时间**：走 0.002 秒
- **代码**：`mujoco.mj_step(m, d)`

### 3.4 到达判断（可选，数据采集必加）

```python
err = np.abs(d.qpos[:7] - q_target).max()
if err < tol:
    到了
```

- **原理**：闭环触发，用误差判断，不用固定时间
- **必须配超时**，防止卡死
- **不做**：可能没到位就闭合夹爪，采到失败数据

## 4. 数据记录（P1 阶段）

每个时间步（或每 N 步）记录：

| 字段 | 含义 | 来源 |
|---|---|---|
| `image` | 相机看到的画面 | `mujoco.Renderer` |
| `qpos` | 七个关节角 | `d.qpos[:7]` |
| `ctrl` | 当前目标 | `d.ctrl[:7]` |
| `gripper` | 夹爪指令 | `d.ctrl[7]` |
| `t` | 仿真时间 | `d.time` |

一条 episode = 从 home 到松开的一次完整抓取。

## 7. 两条时间线（最容易混）

| | IK 迭代 | 仿真时间步 |
|---|---|---|
| 单位 | 次 | 秒 |
| 每次代表 | 数学上更接近解 | 世界前进 0.002 秒 |
| 用哪个函数 | `mj_forward` | `mj_step` |
| 有物理吗 | 没有 | 有 |
| 时间走吗 | 不走 | 走 |
| 数量级 | 600 次 | 几百到几千步 |
