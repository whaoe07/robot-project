## 项目经历

### 项目一：OTFS-ISAC 通感一体化联合接收系统

**重庆邮电大学 · 研究生课题（独立完成）｜2026.03 – 至今**
**技术栈：PyTorch / Transformer / DETR 式集合预测 / OTFS / AMP**

- 独立搭建端到端“仿真—训练—评估”平台，实现时延-多普勒域“多目标感知 + 符号检测”联合链路；以代码指纹校验与逐位等价验证保证结果可复现。
- 用 DETR 式集合预测替代“峰值检测 + NMS”：10 个 query 并行输出无序目标集合，匈牙利匹配建立一一对应，解决目标数未知、候选冗余的互斥性问题；配合候选邻域连续域精化，30 dB 下定位 RMSE **3.42 m**（优于 5.638 m 量化下限），漏检率 **9.3%**（基线 73.6%）。
- 将 AMP 迭代展开为 3 层网络，与感知输出构成 2 轮闭环（重建干扰副本、扣除后回注检测器）；复现 3 类基线并统一信息条件做消融，定位增益来源，主动界定方法适用边界。

### 项目二：基于 MuJoCo 与 ACT 的机械臂抓取模仿学习

**个人项目｜2026.10 – 2026.11**
**技术栈：MuJoCo / Python / PyTorch / IK / ACT / Transformer**

- 独立搭建基于 MuJoCo 的 Franka 机械臂抓取仿真环境，使用阻尼最小二乘逆运动学（IK）实现脚本化专家策略，自动采集 100 条演示数据（约 5800 帧，20 Hz）。
- 实现 ACT-lite 模仿学习策略：4 帧图像与关节历史 + Transformer 编解码 + 16 步动作块；在 50 次随机位置闭环评估中达到 **84%** 抓取成功率（抓取并保持判据），较单帧 MLP 基线（30%）提升 54 个百分点。
- 设计 held-at-end 评估判据与随机化评测流程，定位工作空间边缘失效模式；通过对比实验（训练轮数、历史帧、数据分布、执行步长）定位性能瓶颈，并撰写复盘文档。
