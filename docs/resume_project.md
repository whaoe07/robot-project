# 简历项目条目：MuJoCo 机械臂抓取 + ACT

> 直接复制到简历的“项目经历”里，按需删减。每条都是“做了什么 + 用了什么方法 + 结果”。

## 项目名称

**基于 MuJoCo 与 ACT 的机械臂抓取模仿学习**（个人项目，2026.10–2026.11）

## 项目描述（3 条）

- 独立搭建基于 MuJoCo 的 Franka 机械臂抓取仿真环境，使用阻尼最小二乘逆运动学（IK）实现脚本化专家策略，自动采集 100 条演示数据（约 5800 帧，20Hz）。
- 实现 ACT-lite 模仿学习策略：4 帧图像与关节历史 + Transformer 编解码 + 16 步动作块；在 50 次随机位置闭环评估中达到 **84%** 抓取成功率，较单帧 MLP 基线（30%）提升 54 个百分点。
- 设计 held-at-end 评估判据与随机化评测流程，定位工作空间边缘失效模式；通过对比实验（训练轮数、历史帧、数据分布、执行步长）定位性能瓶颈，并撰写复盘文档。

## 技术栈

- 仿真：MuJoCo、MJCF、EGL 离屏渲染
- 语言 / 框架：Python、PyTorch
- 算法：阻尼最小二乘 IK、行为克隆、ACT（Transformer + 动作分块）
- 工程：Linux（WSL2）、VS Code Remote、Git、tmux

## 30 秒面试版本

> 我在 MuJoCo 里搭了一个 Franka 抓取仿真，用阻尼最小二乘 IK 写了一个 100% 成功的专家，采了 100 条演示数据。先训了 CNN+MLP 的行为克隆，成功率 30%；换成 ACT（图像历史 + Transformer + 16 步动作块）后，50 次闭环评估达到 84%。最大的坑是分布偏移和评估判据，我用闭环评估和 final_z 判据解决了。

## 面试可能追问

| 问题 | 答题要点 |
|---|---|
| 84% 怎么定义的？ | 一次 episode 结束时方块仍在 `final_z > 0.47 m`（初始 0.43，抬离桌面 4cm 并保持）；严格口径 `max_z > 0.5` 是 52% |
| 为什么用 IK 不用 RL？ | 任务固定、环境可控，IK 稳定产出 100% 演示；RL 奖励难设计、训练不稳定 |
| 为什么 ACT 比 BC 好？ | 看 4 帧历史解决单帧歧义；16 步动作块减少复合误差；Transformer 建模动作间依赖 |
| 最大的失败？ | 放慢专家 + 加停顿采 200 条，val 0.012 但成功率 3.3%；静止帧稀释了关键动作的 loss |
| 怎么评估？ | 闭环，每 8 步重规划，50 次随机位置；不用开环数字 |
| sim2real 怎么做？ | 域随机化（质量、摩擦、延迟）、执行器建模、传感器噪声 |
